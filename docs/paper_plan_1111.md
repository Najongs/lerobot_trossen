## 후보 가 — 이동 조작에서 자리 변화가 없는 시연의 한계와 「바로잡는 시연」의 효과 (추천)
- **한 줄 주장(후보)**: 실제 이동 조작 로봇에서 학습 정책이 목표 앞에 서지 못하는 것은 데이터 양이 아니라 바로잡는 장면(어긋난 출발·지나친 뒤 되돌리기·도착 뒤 정지)이 없어서이고, 그 장면을 넣으면 정책 단독 도착률이 오른다. **뒤 절반은 아직 실험 전이다.**
- **이미 있는 결과** (전부 소유자 몫):
  - 1단계 전문가 exec 100 도 9/9 도착 뒤 추가 회전(끝 +97~119°) · 회전 중 남은 회전을 시연 프레임에선 0.2~2.2° 차이로 맞히고 실기 프레임에선 7~20° 크게 잡음 (종합 5절)
  - 모델 없이 시연 명령을 재생한 영상에서도 +8~14° → 원인은 속도가 아니라 장면 · 누적 방향 입력을 바꿔도 예측 1~7° 만 변함 (종합 4·5절)
  - SmolVLA 도 같은 꼴로 실패 → 정책 종류와 무관 [개연] (종합 3절, 볼트 C01) · 1단계 시연 100개는 같은 자리에서 76~89° 만 돈다 (종합 10절)
- **더 필요한 실험**:
  1. 바로잡는 시연 약 60개 → 어긋남 0 / 5 cm·5° / 10 cm·10° × 정책 단독 10회 × 녹화 전·후 모델, 방향과 거리 따로 (현황 문서 5절) — **이것이 없으면 논문이 없다**
  2. 넣는 양을 바꿔 「얼마나 넣으면 되나」(예: 0·20·40·60개, 학습 3~4런 추가 [추정])
  3. 가능하면 팀원 파이제로를 같은 데이터·조건으로 (팀원 계산 자원 필요 — 1호기 V100·2호기 3090 에 안 올라감, 종합 1절)
  4. 선택: 보정기가 만든 시연 vs 사람 시연 (현황 문서 5절 「검토할 선택지」, 정해지지 않음)
- **걸리는 시간** [추정]: 실험 1 은 로봇을 쓰기 시작한 뒤 약 2주(녹화 반나절 · 학습 약 12 h · 실기 약 60회 1~2일 + 재시도 여유). 실험 2·3 은 1~2달.
- **위험**: ① 녹화가 또 미뤄진다(가장 크다 — 10-21 계획이 3주째 안 됐다) ② 결과가 음성이면 짧은 글(워크숍) 몫이 된다 ③ 10회로는 ±2회 차이가 잡음과 잘 안 갈린다 ④ 실험실 배치가 바뀌면 다시 분포 밖 ⑤ 「DART·RaC 의 재현」 이라는 평을 받을 수 있다.
- **겹치는 선행 연구** (초록 기준):

| 논문 | 무엇을 말하나 | 우리와 겹치는 것 / 다른 것 |
|---|---|---|
| DART (arXiv:1703.09327) | 시연 중 잡음을 넣어 시연자가 오류에서 회복하는 법을 보이게 한다. 실물 혼잡 속 집기에서 행동 복제 대비 평균 62% 향상 | 처방이 같다(일부러 어긋난 상태에서 시연). 그쪽은 집기, 우리는 이동 베이스의 도착·정지 |
| DAgger (arXiv:1011.0686) | 정책이 스스로 만든 상태 분포에서 교정을 모아야 순차 예측의 오차 누적을 이긴다 | 우리 녹화안은 사람이 미리 고른 어긋남이라 DAgger 를 손으로 근사한 것 [추정] |
| CCIL (arXiv:2310.12972) | 시연으로 학습한 동역학 모델로 시연 근처의 교정 라벨을 합성한다. 시뮬(내비게이션 포함)에서 교란 회복 향상 | 「보정기를 바로잡는 시연의 선생으로」 와 같은 생각. 그쪽은 학습한 동역학·시뮬, 우리는 카메라 보정기·실기 |
| RaC (arXiv:2509.07953) | 사람이 개입해 익숙한 상태로 되감고 교정 구간을 보여 준 데이터로 미세조정. 양팔 실물 과제 3개에서 데이터 수집 시간 10배 적게 앞섬, 성능이 회복 동작 수에 비례 | **가장 가깝다.** 팀원의 파이제로 리커버리 방식이 이 줄기다. 다른 점: 우리는 베이스 도착, 사람 개입이 아니라 미리 정한 어긋남 |
| MOMASPLAT (arXiv:2611.08372, 2026-11-05) | 이동 조작에서 실행 때 베이스 자세가 시연과 달라 정책이 무너진다 → 새 시점 합성으로 시연을 늘려 처음 보는 베이스 자세에서 기준선 대비 성공률 두 배 이상 | 문제 정의(시연 자리 ≠ 실행 자리)가 같다. 그쪽은 조작 단계의 시점 합성, 우리는 이동 자체의 도착 |
| Data Scaling Laws (arXiv:2410.18647) | 일반화는 시연 수보다 환경·물체 다양성을 따르고, 환경당 시연이 일정 수를 넘으면 더 넣어도 효과가 작다 | 「양은 충분, 빠진 것은 다양성」 의 근거 |
| DemoGen (arXiv:2502.16932) | 시연 하나를 3D 점구름 편집으로 여러 물체 배치로 합성해 공간 일반화를 얻는다 | 조작(2단계 손 자리) 쪽 대안. 이동에 쓸 수 있는지 [추정] |

- **남는 틈** [추정]: 실기 이동 조작 로봇에서 「베이스 도착·정지」 를 따로 떼어, 어긋남 크기와 바로잡는 시연 양을 통제해 비교한 것. **좁다** — 투고 전 RaC·MOMASPLAT 본문을 읽고 다시 판단한다.

## 후보 나 — 어디까지 학습에 맡기고 어디를 인식·제어로 닫는가: 11단계 이동 조작 실기의 실패 진단
- **한 줄 주장(후보)**: 긴 이동 조작에서 학습 정책의 실패는 도착 정밀도에 몰려 있고, 같은 카메라의 측정 기반 보정기가 재학습 없이 회전 오차를 닫는다. 오프라인 지표는 이 실패를 보지 못한다.
- **이미 있는 결과**: 【소유자】 보정기 끝 방향 오차 5.80° → 0.55°(21회 중 20회 1° 안, 전진 0~22 cm 모자람 남음, 종합 6절) · 단계별 실기 기록(종합 2~5절) · 오프라인이 실기와 뒤집힌 목록(종합 9절).
  【팀원】 이동 = 시연 재생 + 카메라 정렬, 조작 = 파이제로 체인 (`configs/chain_all11_recovery_20261030.yaml`).
- **더 필요한 실험**: 보정기 전진 축 · 흔든 자리 10회 · 정책 단독과 보정기 포함을 따로 · 보정 센서가 아닌 독립 측정(바닥 표시·줄자) · 1~3단계 이어 하기.
- **걸리는 시간** [추정]: 보정기 전진 축 코드(로봇 PC) 며칠 + 실기 2~3일.
- **위험**: ① 소유자가 보정기를 「치팅」 으로 본다 — 원하는 연구 방향과 어긋난다 ② 아래 2610.19600 과 크게 겹친다 ③ 팀원 체인이 핵심 몫이면 「개인」 논문이 아니다 ④ 지금 수치는 보정 센서 자신의 값이다.
- **겹치는 선행 연구** (초록 기준, 둘째·넷째 줄은 이번에 초록 일부만 보거나 다시 보지 않음):

| 논문 | 무엇을 말하나 | 우리와 겹치는 것 / 다른 것 |
|---|---|---|
| Cracking Mobile Manipulation (arXiv:2610.19600, 2026-10) | 단독 조작 80% 인 VLA 가 이동 조작으로 묶이면 19%. 실패를 과제 계획·내비게이션과 베이스 자리·국소 조작 셋으로 진단하고 베이스 조정 등 개입으로 시뮬 19 → 47%, 실기 5/20 → 13/20 | **거의 같은 주장(진단 + 개입)이 이미 있다.** 다른 점은 실기 11단계 한 과제를 깊게 판 것 정도 |
| MPVI (arXiv:2606.00985) | VLA 와 모델 기반 경로 계획을 번갈아 써서 추가 학습 없이 BEHAVIOR-1K 과제 진척 113% 향상. 모듈 사이 전환이 어렵다 | 「학습 + 고전 제어」 결합. 그쪽은 시뮬 |
| Precise Mobile Manipulation of Small Everyday Objects (arXiv:2502.13964) | 비전 모델로 서보잉해 작은 물체를 정밀하게 다루는 이동 조작 | 측정 기반 마지막 정렬이 겹친다 [초록 앞부분만 봄] |
| Residual Policy Learning (arXiv:1812.06298) | 불완전한 제어기 위에 학습한 잔차를 얹는다 | 방향이 반대(우리는 학습 정책 위에 제어기) [종합 11절 인용, 이번에 다시 보지 않음] |
| robomimic (arXiv:2108.03298) | 학습 목표와 평가 목표가 달라 멈출 시점 고르기에 따라 성능이 흔들린다 | 실패 요인 「오프라인 평가는 좋은 방향이 아니었음」 의 선행 근거 |

- **남는 틈** [추정]: 작다. 단독 논문보다 국내 학회·워크숍의 실기 보고로 맞다.
