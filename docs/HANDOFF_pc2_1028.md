## 확정 교훈 (수치는 depth 문서)
1. D405 cam_high depth 는 거리를 ≈6% 크게 잰다 → ×0.945. lerobot `read_depth()` docstring 의 「mm」는 틀림(z16 원값, scale 1e-4 m). 조명 끄면 유효 픽셀 25% → 켜면 94%.
2. 직진 오도 ≈2% 과대(0.978). 회전 배율은 1.0 이지만 **직전 동작에 따라 −2~+6°**(앞 0.1 m 뒤 회전이 최악 6°, 뒤 0.1 m 뒤 0.7°, 전환 직후 ≈4°). 사용자 힌트: 앞 캐스터 자세.
3. 오도 안에서 고치기(전환 고정 보정·캐스터 정렬·멈춘 뒤 오도 양으로 재보정)는 전부 실패 — 정지 뒤 1~2° 스텝은 유격 안에서 논다. **돌면서 카메라를 읽다 멈추고, 남으면 4°/s 로 다시 다가가기**가 됨.
4. VO 기준 프레임은 가까운 정지(≤15°)로 — 33° 떨어지면 −2° 치우침. 큰 회전은 15° 구간 + 정지 중 15프레임 중앙값 depth + 양방향 평균.
5. 직진 중 방향 유지는 연속 제어가 안 된다(VO 0.3 s + 베이스 0.3 s 지연 → 게인 2.5 는 7° 발산, 1.0 은 −3.9°). 후진 중 유지는 12° 흔들려 껐다. 지금은 도착 후 회전 모듈로 되돌리는 방식.
6. 문헌(21편): 우리 문제 ①②③ 선례 거의 없음. 처방은 「베이스를 action 에서 빼거나 조작 직전 비전 재정렬」. 바로 쓸 아이디어 5개는 literature 문서 ③ 절(Mobile ALOHA 청크 지연 오프셋, 청크 변위 표현, 추론 시 정렬 오버라이드, 시작 자세 성공률 지도).
