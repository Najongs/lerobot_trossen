## 0. 무엇을 하려 했나
- 과제: Trossen Mobile AI(양팔 + 이동 베이스 + 카메라 3대)로 실험실 11단계(튜브 → 비커 → 냉장고 → 선반)를 학습한 정책으로 수행.
- 목표(10-08 계획): 단계마다 **흔든 시작(±15 cm·±15°)에서 70%**. 판정은 실기만 센다.
- 데이터: 우리 녹화 1,392 ep + 외부(GIST) 18,223 ep, 합 6,461,644 프레임 (DGX 실측 10-30). 실제 녹화 주기는 표기 30 Hz 가 아니라 약 21 Hz.
- 사람·장소: 학습 1호기(DGX1)·2호기(sandia) · 실기 로봇 PC(Trossen_PC1, 사람이 실행).

- 흔든 자리(±15 cm·±15°) 실기 **0회** — 목표 판정 조건을 한 번도 안 돌렸다.
- 청크 100 세대로 4~11단계 실기 **0회** (6단계 1회는 출발 자세 미확인으로 무효). 11단계 이어 하기 1→11 시도 없음.

## 9. 인사이트 (확정도 순 — 살을 붙일 때 근거 표를 단다)
1. 홀드아웃·오프라인 지표는 실기를 대신하지 못한다 (실기)
2. 모델은 카메라로 자리·장면 차이를 보정하지 않는다 — 조작은 손 자리, 이동은 회전량에서 같은 꼴 (실기 + 오프라인)
3. 출발 실패는 청크 길이 문제였다 (실기)
4. 짧은 exec 는 이동·조작 모두 나쁘다 (실기, 회차 적음)
5. 도착 뒤 멈추기를 배운 적이 없다 — 시연 끝 뒤 정지 구간이 없다 (실기 + 오프라인)
6. GIST 는 30% 고정 가중으로 섞으면 득 (오프라인 + 실기 소수)
7. 시드 폭이 레시피 차이보다 크다 (오프라인)
8. 단계 원핫은 장면보다 약하다 (실기)

## 10. 추후 연구 방향 — 후보 질문 (다음 단계에서 순서를 정한다)
- 가. **장면 일반화**: 지금 장면에서 출발을 흩뜨린 시연 + 도착 뒤 3 s 정지를 녹화하면 1단계가 흔든 시작에서 서나 (추가 녹화 계획)
- 나. **도착 판단**: 정지를 정책 안(데이터)에서 배우게 할지, 정책 밖(실측 예산·도착 래치)에서 막을지
- 다. **손 자리 일반화**: 조작 단계에서 물체 자리가 바뀌면 따라가게 — 자리 다양화 녹화가 본 처치 후보
- 라. **모델 구조**: 잠재 변수가 안 쓰이는 지금 ACT 에서 그 부분을 빼거나 바꿀 이유가 있나
- 마. **평가 체계**: 흔든 자리 10회·성공 기준(5 cm·±5°·정지)을 표준 절차로 굳히기
- 바. 4~11단계와 이어 하기로 넓히는 시점 — 1~3단계가 어디까지 오면 넘어가나
- 이미 반증된 것은 다시 제안하지 않는다: 베이스 속도 입력(오프라인 반증), 머물기 감독(실기 반증), 시간 앙상블(실측 반증)
