## 열 추가 규칙
새 후보(청크 100 c1~c4, SmolVLA 30K, 5라운드 변형)는 **첫 실기 회차 때 열을 만든다.** 열 이름은 허브 이름의 핵심(`c100_m1 15K` 처럼). 같은 모델의 exec 가 다르면 열을 나눈다(`전문가 e30` / `e100`).

## 읽는 규칙
- n < 5 인 칸은 성공률로 읽지 않는다(「해 봤다」 까지).
- 70% 판정은 **B 열, n ≥ 10** 에서만.
- 러너 자동 완료 ≠ 성공. 성공은 사람이 본 것만.
