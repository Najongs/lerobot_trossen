## 실행 조건 변경 — 팔 한 틱 이동 상한 (C-2 부터)

`scripts/eval_najy.sh` 에 `MAX_REL`(기본 **0.1 rad**) 을 넣어 `--robot.{left,right}_arm_max_relative_target` 을 건다.
정책 action 이 현재 자세에서 0.1 넘게 떨어지면 그 틱엔 0.1 만 간다(관절별, 21 Hz 에서 최대 약 2.1 rad/s). 실기 고장 방지용 —
팀이 이전 단계별 eval 에서 쓰던 값이다. 기존 페이싱(`velocity_safety_factor=0.4`)은 그대로 위에 걸린다.
**C-1 까지는 이 상한 없이 돌았다** — 10/06 C-1 이전 회차와 비교할 때 조건이 다르다. 같은 조건으로 보려면 `MAX_REL=none`.

지난 기록에 0.1 을 걸었다면 잘렸을 틱 (|action − state| 관절 최대 > 0.1, eval 데이터셋 실측 — 실제 상한 하에서는 궤적이 달라지므로 근사):

| 기록 | 잘렸을 틱 | |action−state| 관절 최대 (중앙 / p95 / 최대) |
|---|---|---|
| 1006_1038 base t05 e100 (성공) | 13.0% (44/339) | 0.006 / 0.185 / 0.484 |
| 1002_1422 base t05 e30 (성공) | 16.7% (44/264) | 0.017 / 0.182 / 0.559 |
| 1002_1150 m1 t04 e30 (성공) | 1.3% (21/1571) | 0.014 / 0.061 / 0.203 |
| 1002_1403 m1 t05 e30 (정지) | 0% | 0.002 / 0.019 / 0.030 |
| 학습 task05 (file-000, 398프레임) | 15.8% | 0.006 / 0.152 / 0.289 |

- base 모델·시연 텔레옵은 빠른 구간의 13~17% 틱이 0.1 을 넘는다 → base 는 상한 아래서 **느려질 수 있다** [추정]. 시작·청크 경계 점프(0.48~0.56)는 5틱(약 0.24초)에 나눠 간다.
