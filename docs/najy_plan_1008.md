# NAJY 계획 정비 — 태스크별 70% 를 흔들린 시작에서 (2026-10-08, DGX·사용자 합의 초안)

> 현황 정본은 [`najy_overview.md`](najy_overview.md), 회차 기록은 `eval_najy_results_<MMDD>.md`. 이 문서는 **왜·무엇을·어떤 순서로** 만 적는다.
> 「결정 대기」 표시는 사용자 답을 기다리는 칸이다. 답이 오면 이 문서를 고치고 날짜를 적는다.

## 0. 목표 (사용자, 10/08)
- **태스크별 성공률 ≥ 70%** 가 최소선. 체인 전체 성공률은 지금 걱정하지 않는다 (단계 재시도를 전제로 한 숫자다 — 70%¹¹ ≈ 2%).
- **시작 위치는 흔들린다.** 같은 자리를 노리지만 매번 다르다 → 70% 는 「흔들린 시작」 조건에서 잰다. 폭은 결정 대기(§5).
- 모델은 ACT 가 주력이고 SmolVLA 도 후보다 (떨림은 추론 경로 처방이 있다).

## 2. 평가 규약 (이게 없으면 70% 는 잴 수 없다)
- **성공 기준 한 줄/태스크** — 사람 판정. 예: t04 「튜브의 액체가 비커에 들어갔다」, t05 「두 튜브가 모두 트레이 안」. 11개 표는 결정 대기(§5) 뒤 `eval_najy.md` 에 적는다.
- **시작 분포 둘**: A = 시연 자리(현재 규약, 시연 첫 프레임 대조) · B = 흔든 자리(±X cm·±Y°, 물체 위치 소폭) — X·Y 는 결정 대기.
- **표본**: 조건당 ≥5회. 지금까지 태스크당 1~4회라 「낮다」 는 아직 측정이 아니다.
- **기록**: 출발 시각·성공·실패 지점·첫 2 s 팔 이동·clamped·루프 Hz·시작 자세 오차·사람 관찰 한 줄 (지금 양식 그대로).

## 3. 순서 — 관문(G)마다 숫자가 나와야 다음으로
### G0. 실행 층 걷어내기 + 지금 데이터의 천장 (이번 주, 새 데이터 없이)
| 누가 | 무엇 | 산출 |
|---|---|---|
| 로봇 PC | t05 전문가 exec 30 vs 100 A/B, t04 전문가 e100 (1008 §6) | 「출발이 청크 길이 문제인가」 실기 확정 |
| 로봇 PC | SmolVLA 11단계 30K: t05·t04 rec/long (1008 §7) | 출발·성공·떨림 — ACT 전문가와 나란히 |
| 2호기 | c1(M1+청크 100) 15K → `start_chunk_check` · public | 11단계 모델이 청크 100 으로 출발을 담나 |
| 1호기 | c2(+드롭아웃)·c3(nopad)·c4(둘째 시드) 15K → 채점·public | 체인용 후보 레시피 |
| 2호기 | 잔떨림 저역 통과 창 분석 | 러너 다듬기 설계 근거 |
| 로봇 PC | 가장 나은 후보로 **시연 자리(A) t04·t05 5회씩** | **천장**: 지금 데이터로 분포 안에서 몇 % 인가 |
| 로봇 PC | **이동 단계 — 묶음 모델의 첫 제대로 된 실기** (1008 §8): t06·t10 을 M3(이동 4단계 묶음, 20D)와 t06 전문가(14D·청크 100)로 각 1~2회, 장면 대조 뒤 | t06·t10 은 어떤 모델로도 실기가 없다. M3 는 1회(1156)뿐이고 그것도 t03 장면이었다 |
G0 통과 기준: 분포 안 t04·t05 에서 출발이 되고 성공률 숫자가 나왔다. 70% 아래면 데이터 양·품질 문제가 먼저다.

### G1. 능력 반경 (로봇 6~9회)
- 같은 후보로 시작을 **10 cm · 10° · 20 cm** 어긋나게 3회씩 (t04 또는 t05). 어디서 무너지나.
- 오프라인 보조: 로봇 PC 가 이미 녹화한 어긋난 위치 프레임(1040·1046·1047·1101·1102)에 ACT 후보와 SmolVLA 를 넣어 첫 청크 방향 비교 — 로봇 없이 DGX 에서.
- 산출: **반경 r** (이 안에서는 70% 가능, 밖에서는 무너짐). 재수집 폭은 r 보다 넓게 잡는다.

### G2. 파일럿 태스크 하나로 아키텍처·데이터 결정 (결정 대기: 태스크·폭)
- 후보 t04 붓기: 성공 기준 분명, 전문가 있음, 공유 장면 문제도 같이 보인다.
- 재수집 명세: 시작 B 분포(폭은 G1 의 r 보다 넓게), 물체 위치 소폭 흔들기, **녹화 시작 전 2 s 정지 없음**(출발 정지점의 뿌리), 중간 상태에서 시작하는 복구 시연 몇 개, 21 Hz 실측 기록. 50회 안팎.
- 같은 데이터로 **ACT(청크 100, 머물기 감독 없음) 와 SmolVLA 미세조정** 둘 다 학습 → B 분포에서 10회씩 → 70% 달성 여부와 둘의 차이. **이 한 번의 비교가 나머지 10개의 모델을 정한다.**

### G2' GIST 혼합 — 재수집 전에 있는 「다른 현장」 데이터 (10/09 추가, sim §94.38)
- GIST 가 같은 11단계 프로토콜을 다른 현장에서 찍은 17셋(태스크당 800~2,600ep)이 DGX 에 있다. 형식이 우리와 같다(16D·같은 카메라·30 fps).
- §66.1 의 「섞으면 나빠진다」 는 가중치 없는 프레임 비례 혼합 + 홀드아웃 MAE 기준이었고, 「희석인지 데이터 탓인지」 는 미결이었다. 지금 질문(흔들린 시작·장면 변화)은 다르다.
- 1호기 15K 두 시드(`c100_gist30`, GIST 30% 가중치 고정) → 우리 홀드아웃 유지 + GIST 홀드아웃(다른 현장의 처음 보는 시작) 상승 + **실기 프레임(O6)** 으로 판정. 되면 G2 재수집의 폭을 줄일 수 있고, 안 되면 재수집으로.

### G3. 확장
- 파일럿 결과대로 나머지 조작 태스크 재수집·학습. 이동 단계(t01·03·06·10)는 **학습 대신 오도메트리 스크립트** 검토 — 장면 민감도가 가장 컸던 단계들 (결정 대기).
- 체인은 그 뒤: 단계 k 가 끝낸 자리가 k+1 의 반경 안인지 재고, 아니면 리셋·경계 시연.
